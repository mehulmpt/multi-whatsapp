# Privacy

Multi Account for WhatsApp Web runs entirely in your browser.

**What it stores**, all in your Chrome profile on this device:

- In the extension's local storage: your account list (the names and colours you choose, the phone number WhatsApp Web shows for each linked account, last-used times), your settings, and the total storage size of web.whatsapp.com.
- In web.whatsapp.com's own storage: a copy of each inactive account's WhatsApp Web session. WhatsApp Web already keeps this data there. The extension only keeps one copy per account so it can switch between them.

**What it never does:**

- It doesn't read, collect or index your messages, contacts or media.
- It doesn't send any data anywhere. The extension makes no network requests.
- It has no analytics, tracking, ads, remote code or third-party services.
- It doesn't sync anything to your Google account.

**Removing data:** Removing an account in the extension deletes its saved session. Uninstalling the extension deletes the account list. Saved sessions inside web.whatsapp.com's storage stay until you remove them in the extension first or clear that site's data in Chrome (*Settings → Privacy and security → Site settings → web.whatsapp.com → Delete data*).
